# Clasificación de Tuberculosis Pulmonar en Radiografías de Tórax Mediante Transfer Learning con EfficientNet-B4

Proyecto de detección de tuberculosis pulmonar en radiografías de tórax usando EfficientNet.
## Ambiente 
En requirements.txt menciona:
tensorflow
numpy
pandas
matplotlib
scikit-learn
opencv-python

Instala
pip install -r requirements.txt

## Ejecución

terminal de visual studio
1. cd src
2. python train.py
